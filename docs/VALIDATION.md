## 窗口恢复修正

【BUG表象】：在 Windows 分数缩放下，保存 1300 宽窗口后重新创建窗口得到 1302 宽。

【真实根因】：创建窗口时的尺寸换算与保存时使用的外框 bounds API 对不可见窗口边框的处理不同。

【修复方案】：窗口创建后，使用与保存相对应的外框 bounds API 应用记忆尺寸；不通过减去固定像素补偿。

【修改代码】：

```diff
 win = new BrowserWindow({ width, height, x, y, ... })
+win.setBounds({ width, height, ...(x === undefined ? {} : { x }), ...(y === undefined ? {} : { y }) })
```

【回归校验】：桌面测试实际调整窗口、关闭、读取保存结果并重启，确认恢复宽度与保存结果一致；同时验证布局和标签状态没有丢失。
