## 根因与改动

【BUG表象】：原版约 101 MiB、没有单栏、配色切换需要额外保存。

【真实根因】：打包保留完整依赖树且携带全部运行时语言资源，布局模型未定义 single，外观与游戏启动草稿共用保存入口。

【修复方案】：编译合并依赖而保留必要浏览器运行环境；扩展布局模型；为外观提供独立、自动保存入口；在后台实施实例保护校验。

【修改代码】：

```diff
- layoutIds = ['columns', 'rows', 'left-wide', 'right-wide', 'quad']
+ layoutIds = ['single', 'columns', 'rows', 'left-wide', 'right-wide', 'quad']
- defaultWorkspace().layout = 'columns'
+ defaultWorkspace().layout = 'single'
- main build: packages = 'external'
+ main build: bundle = true; external = ['electron']
+ workspace: sidebarWidth, sidebarCollapsed, sidebarExpandedWidth, closedTabs
+ instance options: protected
+ appearance.save: only theme, accent, reduceMotion
+ assertInstanceUnprotected(instance) before destructive instance operations
```

完整实现见 shared/workspace.ts、shared/appearance.ts、shared/instance-list.ts、src/App.vue、src/components/PaneView.vue、electron/main.ts 与 scripts/build.mjs。

【回归校验】：npm test；npm run build；node scripts/smoke.mjs；打包后执行 node scripts/package-smoke.mjs 指定解压后的程序。测试只使用临时目录，保持现有游戏文件不变。
