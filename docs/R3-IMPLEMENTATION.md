# 0.1.0 r3：运行环境、账户、Mod 管理与下载

本轮在用户确认调研方案后实施。继续使用 Electron / Vue / TypeScript，原生迁移单独进行。

## 功能

- 全局与实例设置均可展开 Java 列表，显示版本、架构和完整路径；支持选择 java.exe、添加/移除扫描目录。新增目录最多递归 5 层、全局扫描最多 10000 个目录，不跟随子目录链接。扫描目录持久保存。
- 添加离线账户，名称为 3–16 位字母、数字、下划线；使用标准 OfflinePlayer 名称派生 UUID。离线会话不依赖微软 Client ID、令牌缓存或网络；微软账户与离线账户明确区分。
- 自动/手动内存；实例支持继承全局、自动、手动。自动策略结合系统可用内存、预留空间、Java 位数和模组规模；启动日志记录最终堆上限。旧配置中的固定内存以手动模式迁移，避免覆盖用户选择。
- 实例卡片右侧 Mod 入口：读取 Fabric、Quilt、Forge/NeoForge TOML、mcmod.info 基础信息；搜索、导入 JAR、启用/禁用、移至回收站。禁用通过 .jar.disabled 实现，不修改 JAR 内容。损坏文件单独显示错误。共享目录明确提示；实例保护、同目录运行和安装锁在主进程校验。
- 单一下载入口，分类为游戏、Mod、资源包、光影；原版/Fabric 游戏安装流程保留。旧 install 标签仍兼容，不丢弃已保存会话。
- Modrinth 在线搜索、分页、选择版本、按目标实例筛选、解析必要依赖、文件校验、安装；文件分别放入目标游戏目录的 mods / resourcepacks / shaderpacks。
- CurseForge 相同适配接口；API 密钥独立加密保存，不进入界面状态快照。未配置或平台未提供下载链接时明确提示，并提供官方项目页入口。
- 资源下载先全部暂存并校验大小/哈希，完成后以排他写入提交；失败/取消清理暂存，提交失败回滚本次创建的文件；已有同名不同内容、被禁用的同名模组、已能识别的重复 Mod ID 均阻止安装。依赖循环、深度和数量超限明确报错。
- 字体 90%–150%，立即生效并保存；字体大小统一受缩放变量控制，不使用整窗缩放。删除重复英文眉题、下载装饰横幅、空实例宣传卡和侧栏便携宣传块；默认单栏不变。

## 实现边界

- 微软登录继续使用设备码授权，仍需要获准访问 Minecraft 的 Hakf Client ID。没有真人授权，未验证真实微软登录和进入游戏。
- 离线账户已实测创建、保存、切换和会话生成；未自动启动完整游戏窗口。离线身份不能通过正版服务器验证。
- CurseForge 已实现并通过模拟 API 数据测试；未提供真实 API 密钥，未声称真实联网测试通过。
- Mod 解析用于名称、版本和基础重复识别，不是完整加载器解析器。未知元数据仍按文件管理；不会断言所有 Mod 冲突均已检测。
- 本轮不安装整合包，不批量更新或替换已有 Mod，不自动安装 Forge/NeoForge，不下载 Java。
- 资源文件单个限制 512 MiB；必要依赖最多 100 个、深度 16。资源下载失败后重新下载；不承诺断点续传和跨重启恢复。任务记录仅保留本会话。

## 根因修复记录

【BUG表象】：加入 Java 扫描目录数组后，保存设置提示 “An object could not be cloned”。

【真实根因】：对 Vue 响应式设置执行浅复制后，嵌套的 javaRoots 仍是 Proxy，Electron 的结构化复制不支持该对象；表象发生在保存设置，根源在渲染层与桌面通信的数据边界。

【修复方案】：在唯一的渲染层 API 入口将 JSON 消息序列化为普通数据；继续保留主进程输入校验，不吞异常，也不在每个控件里重复绕过。

【修改代码】：src/store.ts 的 api 函数：

```diff
- return window.launcher.invoke<T>(method,payload)
+ const message=payload===undefined?undefined:JSON.parse(JSON.stringify(payload))
+ return window.launcher.invoke<T>(method,message)
```

【回归校验】：tests/ipc.test.ts 使用嵌套响应式对象与真实 structuredClone 检查通信值；桌面测试通过界面选择 Java、添加扫描目录、保存并重启后确认路径和设置仍在。测试同时保留无参数 snapshot 的 undefined 语义。

## 为什么包仍约 90 MiB

r2 已将应用代码归档从 61482389 字节缩小到 2497611 字节，便携包从 105709540 缩小到 94205018 字节（约 89.8 MiB）。剩余大部分为 Electron 自带 Chromium / V8 / Node 和图形、媒体、国际化组件。解压后 Electron 主程序单文件 250129920 字节，不能拿该解压大小直接与压缩包大小比较。

业务代码进一步压缩不可能抵消整个浏览器运行环境。当前只保留 zh-CN/en-US 语言资源并合并依赖，不删除必要的渲染或媒体组件。原生迁移或改用系统 WebView 是另一个技术方案，未在本轮擅自执行。
